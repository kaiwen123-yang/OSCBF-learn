# 完整抓放参考路径的 TCP 与奇异性审查

本目录是 2026-11-07 的纯离线数值检查，没有连接 CAN、调用 SDK、运行机械臂或打开图形窗口。FK 及间隙相关量均来自厂家 URDF 模型，TCP 偏置 `[0, 0, 0.1425] m` 仍是名义值，没有现场标定声明。

## 检查方法

```bash
env -u LD_LIBRARY_PATH JAX_PLATFORMS=cpu ./envs/oscbf/bin/python -I scripts/audit_task_paths.py --working-pose-study
```

脚本对比 `scripts/run_pick_place.py` 中实际 `path_arrays()` 的输出，确认原规划路径点与速度重定时完全一致；不导入或执行硬件入口。两个倍率均为 1.5。检查每个保存点及每个线性插值段，参考时间间隔不超过 10 ms、单关节采样增量不超过 0.001 rad。内部路径点采用执行器的右侧导数，最后参考时刻前馈为零。真实误差反馈会改变参考时间推进速度，但仍落在这些相同的线段内。

对 Jacobian 行列式的符号变化进行数值求根，对低最小奇异值的区间进行有界细化，避免把“离散采样最小奇异值大于零”误当成连续插值不会穿过奇异点。有限采样及数值求根不是所有扰动状态的解析证明。

TCP Jacobian 已通过中心差分核对（平移及基坐标角速度）；具体误差见 `audit.json`。度量为当前单位和权重下的 `P = J_tcpᵀ J_tcp`，即 `W_o = I`，线速度行单位为 m/rad，角速度行单位为 rad/rad；条件数受单位和权重选择影响。

以 `alpha_joint = 3 /s`、0.001 rad/s 量化和当前 0.30 rad/s 速度上限检查，所有参考点的“关节限位 CBF＋速度盒”均存在可行速度。但零位计划的 return_initial 有 66 个采样点，其原参考速度违反关节 CBF，意味着安全过滤会改变返回零位的推进，不可直接假定原轨迹仍以原速度完成。这里没有加入障碍、桌面或碰撞约束；可行性结论只针对上述关节约束。

## 首版完整任务建议

采用原右侧 pregrasp 到位姿态作为滤波任务的起点与返回点，重新通过 MoveIt 规划完整任务。精确角度、弧度和来源保存在 `working_pose_proposal.json`：

```text
q_deg = [-14.9272868457, 94.1138520081, -72.9428084043,
         -0.0037002067, 73.8262076229, -14.9277797609]
TCP xyz ≈ [0.3000262, -0.0799991, 0.1129932] m
```

现有左侧 retreat 终点到上述右侧准备姿态的 2001 点直线关节插值，`σ_min = 0.1495648`、最大度量条件数 `143.20`。这是数值候选连接，**没有被当作已通过 MoveIt 碰撞检查的执行计划**。

在现有中间工作段和该候选连接的 4443 个参考点上，枚举每轴 ±0.01 rad 误差盒的全部 64 个角点，共 284352 个状态，最小 `σ_min = 0.1487484`、最大度量条件数 `144.956`，行列式符号均为负。可据此暂设 `σ_min >= 0.10` 作为该工作区域的工程数值检查值；它不是厂家限值，也不是对整个误差盒的解析证明，必须对重新生成的完整路径及过滤后轨迹再次核对。

从当前实际姿态到新准备姿态的运动，须作为现场操作者单独启动的原关节跟踪准备步骤；不要把准备运动可能跨越奇异区间的部分计入“全程满秩 OSCBF 任务”。新任务的起终点相同还可能使 pregrasp 成为零长度轨迹，规划/执行器需要显式处理该情形，而不能让不足两个点的轨迹进入原插值函数。

## 论文对应

核对所附 `OSCBF_IROS2025_Morton_Pavone_arXiv_v3.pdf` 第 4 页 IV-B、公式 (18)–(28)：

- (18)–(21) 先形成共同任务空间名义速度及其关节映射。完整任务若采用该名义控制器，普通 CBF 和 OSCBF 必须共同采用。
- (23)–(26) 对比的是安全过滤的目标度量。一般式是 `P = Nᵀ W_jᵀ W_j N + Jᵀ W_oᵀ W_o J`，`N = I − J# J`。
- 当前 `plane.py` 省略 `N` 的六轴特例要求方阵 Jacobian 满秩。秩亏时直接使用 `JᵀJ` 不再正定。加入任意 `epsilon I` 不等于完成论文意义下的秩变化处理。
- 在确切秩亏处使用完整 Moore–Penrose 零空间项，可使该二次型恢复正定，但这本身没有解决近奇异名义逆映射、秩切换连续性及实际可行轨迹问题。首版优先避开这类工作区。
- (28) 说明如何加入关节速度限制；论文也明确指出单独追加输入限制并不自动保证整个安全集的前向不变性。

## 文件

- `audit.json`：来源 SHA-256、逐阶段及细化奇异点、候选姿态、数值检查范围。
- `*_samples.csv`：保存点与线性插值采样、TCP、奇异值、条件数、关节和速度约束余量。
- `working_pose_proposal.json`：精确工作姿态、返回连接和扰动角点检查。
- `alternate_pose_candidates.json`：若干候选姿态与直线连接的比较，仅用于离线选择。
- `console.log`：可复跑命令的文本输出。
